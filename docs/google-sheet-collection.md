# 구글 시트로 조원 답변 자동 취합하기

조원들이 입력한 변수를 **하나의 공유 구글 시트**에 모은 뒤,
진행자(Facilitator)가 그 표를 복사해 STEEP 앱에 붙여넣는 방식입니다.
별도 서버·코딩이 필요 없고, 구글 시트의 실시간 협업 기능을 그대로 활용합니다.

```
조원들이 공유 시트에 입력  ──복사──▶  STEEP 앱 "2. 변수 입력"에 붙여넣기
   (실시간으로 쌓임)                    (작성자·점수까지 자동 인식)
```

## 1) 진행자: 공유 시트 만들기 (1분)

1. [sheets.new](https://sheets.new) 로 새 구글 시트 생성
2. 1행에 헤더 입력 — 앱의 **`📋 시트 헤더 복사`** 버튼을 누르면 아래가 복사됩니다:

   | 변수 | 작성자 | 영향도(1-5) | 불확실성(1-5) |
   |------|--------|-------------|----------------|

   > 또는 이 저장소의 `google_sheet_template.csv` 를 시트에 가져오기(파일 → 가져오기)해도 됩니다.
3. 우측 상단 **공유 → "링크가 있는 모든 사용자: 편집자"** 로 설정 → 링크 복사
4. 링크를 조원들에게 전달

## 2) 조원: 변수 입력

- 전달받은 링크를 열고, **빈 행에 한 줄씩** 입력합니다.
  - `변수` 열: 사업 환경에 영향을 줄 요인 (필수)
  - `작성자` 열: 본인 이름 (선택, 추후 출처 구분용)
  - `영향도` / `불확실성` 열: **세미나 토론 후 채워도 됩니다** (비워두면 앱에서 평가 가능)
- 여러 명이 동시에 입력해도 실시간으로 쌓입니다.

## 3) 진행자: 앱으로 가져오기

1. 시트에서 데이터 범위를 **드래그 선택 → 복사**(Ctrl/Cmd+C)
   - 헤더 행을 포함해도 됩니다 (앱이 자동으로 무시)
2. STEEP 앱 → **2. 변수 입력** → 큰 입력칸에 **붙여넣기**(Ctrl/Cmd+V)
3. **＋ 변수 추가** 클릭
   - 탭으로 구분된 표를 감지해 **변수·작성자·영향도·불확실성을 한 번에** 채웁니다
4. **3. AI STEEP 분류** 로 진행 → Claude가 자동 분류 + 중복/표현 정리

## 열 순서 규칙

앱의 표 파서는 **열 순서**로 읽습니다:

```
1열: 변수(필수)  2열: 작성자  3열: 영향도(1-5)  4열: 불확실성(1-5)
```

- 영향도·불확실성에 1~5 범위 밖이거나 비어 있으면 0(미평가)으로 처리되어,
  세미나의 **4단계 평가**에서 채울 수 있습니다.
- 변수 텍스트만 있는 줄은 그대로 변수로 추가됩니다.

## 팁
- 조별로 시트 **탭(시트)** 을 나누면 조별 취합이 깔끔합니다.
- 중복 변수는 3단계 AI 분류가 정리해 주지만, 앱의 **병합(JSON)** 기능도 중복 텍스트를 자동 제외합니다.
- 평가 점수까지 시트에서 받으면 4단계를 건너뛰고 바로 **5단계 매트릭스**를 볼 수 있습니다.
