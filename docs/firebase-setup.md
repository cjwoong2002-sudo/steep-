# 조별 실시간 공유 설정 (Firebase)

같은 **조 + 방 코드**를 선택한 참가자끼리 비즈니스 캔버스를 실시간으로 공유합니다.
진행자가 Firebase 프로젝트를 한 번 만들면(약 5분), 참가자는 **조만 선택**하면 자동 연결됩니다.

```
조원 각자 입력  ──실시간 발행──▶  Firebase Realtime DB  ──실시간 구독──▶  조 전체 캔버스 보기
```

## 1) 진행자: Firebase 프로젝트 만들기 (1회, ~5분)

1. [console.firebase.google.com](https://console.firebase.google.com) → **프로젝트 추가**
2. 좌측 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치 선택 → **테스트 모드로 시작** (또는 잠금 모드 후 아래 규칙 적용)
3. **프로젝트 설정(⚙) → 일반 → 내 앱 → 웹 앱 추가(`</>`)** → 앱 등록
4. 표시되는 `firebaseConfig` 객체를 복사 (apiKey, authDomain, **databaseURL**, projectId, appId …)
   - `databaseURL`이 반드시 포함되어야 합니다. 없으면 Realtime Database 페이지 상단의 URL을 사용하세요.

### 보안 규칙 (Realtime Database → 규칙)
세미나용 최소 규칙(공개 read/write — 행사 종료 후 비활성화 권장):
```json
{
  "rules": {
    "rooms": { ".read": true, ".write": true }
  }
}
```
> Firebase web config의 apiKey는 **비밀이 아니라 공개 클라이언트 식별자**입니다. 실제 접근 제어는 위 DB 규칙으로 합니다. 민감 데이터를 다루지 않는 세미나용이므로 공개 규칙으로 충분하지만, 행사 후에는 규칙을 잠그거나 DB를 비우세요.

## 2) 진행자: 앱에 config 연결 (둘 중 하나)

**A. 코드에 내장 (권장 — 참가자는 아무 설정 불필요)**
`index.html`의 `FIREBASE_CONFIG` 상수(주석 `⬇⬇⬇ Firebase 설정 교체 지점 ⬇⬇⬇`)에 config를 채우고 커밋/배포.
이후 참가자는 URL 접속 → 조 선택만 하면 됩니다.

**B. 화면에서 붙여넣기**
헤더 **👥 조 공유** → config JSON 붙여넣기 → 방 코드 입력 → **실시간 공유 사용** 체크 → 저장 & 연결.
(이 방식은 붙여넣은 기기에만 저장됩니다.)

## 3) 참가자: 사용

1. 같은 URL 접속 → **세션 설정**에서 본인 **조** 선택
2. 헤더 **👥 조 공유** → **실시간 공유 사용** 체크 → 저장 & 연결
   - (진행자가 코드에 config를 내장했다면 config 입력 불필요)
3. **Activity III**에서 캔버스 작성 → **👥 조 전체 캔버스 보기**로 조원들의 As-Is/To-Be를 실시간 열람

## 방(room) 구분
- 방 ID = `방코드_조` (예: `lg2026-1차_1조`)
- **차수가 다르면 방 코드를 다르게** 주면 데이터가 섞이지 않습니다. (예: `lg2026-1차`, `lg2026-2차`)

## 무엇이 공유되나
각 참가자의 `프로필(조·성함·직책)`, `변수`, `시나리오`, `캔버스(As-Is/To-Be)`, `기회/위협`이 발행됩니다.
현재 UI는 **Activity III 캔버스 열람**을 제공하며, 동일 데이터로 추후 조별 STEEP/기회·위협 취합 뷰도 확장 가능합니다.

## 동작 안 할 때
- `databaseURL` 누락이 가장 흔한 원인 — config에 포함되었는지 확인
- 헤더 상태칩: 🟡 연결 중 / 🟢 접속(n명) / 🔴 오류 / ⚪ 미설정
- 오프라인이거나 config가 없으면 **개인 모드**로 정상 동작합니다(공유만 비활성).
