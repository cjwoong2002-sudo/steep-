# 시드 리스트에 대해 — 반드시 읽어주세요

## 왜 시드가 필요한가

무료로 **"전 종목 시가총액 순위"를 주는 API 는 중국(akshare)뿐입니다.**
한국·미국·일본·유럽은 그런 무료 엔드포인트가 없습니다.

그래서 이 도구가 말하는 "지역 시총 상위 100"의 정확한 의미는

> **이 시드 리스트 안에서의** USD 환산 시총 상위 100

입니다. 시드에 없는 대형주는 애초에 후보에 들어오지 못합니다.
이건 도구의 버그가 아니라 무료 소스의 구조적 한계입니다.

## 지금 들어 있는 시드의 출처와 한계

현재 파일은 **모델 지식(2026-05 기준)으로 작성한 각 지역 대형주 목록**입니다.
직접 검증되지 않았으므로 다음을 전제하세요:

- 티커 오탈자, 상장폐지·티커 변경 종목이 섞여 있을 수 있습니다
- 실행 결과의 **`조회실패` 시트**에 문제 티커가 그대로 남습니다 → 그걸 보고 이 파일을 고치세요
- 지역별 종목 수: kr 약 120, us 약 165, jp 약 130, cn 약 165, eu 약 245

상위 100을 뽑으려면 후보가 100보다 넉넉히 많아야 하므로 일부러 여유를 뒀습니다.

## 공식 소스로 갈아끼우는 방법 (권장)

`scripts/refresh_seeds.py` 를 **로컬에서** 실행하면 공개 소스에서 구성종목을 받아옵니다.
(이 도구를 만든 환경은 네트워크가 막혀 있어 실행 검증을 하지 못했습니다.)

```bash
python scripts/refresh_seeds.py --region us    # Wikipedia S&P 500 표
python scripts/refresh_seeds.py --region cn    # akshare A주 전종목 시총 상위
```

일본·유럽·한국은 자동 수집이 어렵거나 사이트 구조가 자주 바뀝니다. 수동 경로:

| 지역 | 공식 소스 | 형식 |
|---|---|---|
| 한국 | KRX 정보데이터시스템 → 전종목 시세 | CSV 다운로드 |
| 일본 | JPX → TOPIX 구성종목 / 東証上場銘柄一覧 | Excel |
| 유럽 | STOXX Europe 600 구성종목, 또는 각 거래소 지수 페이지 | CSV/Excel |
| 미국 | Wikipedia S&P 500, 또는 나스닥 스크리너 | HTML/CSV |
| 중국 | akshare 로 자동 (유일하게 전종목 무료) | API |

다운로드한 파일에서 티커만 추출해 `<지역>.txt` 로 저장하면 됩니다.
형식은 한 줄에 티커 하나, `#` 뒤는 주석입니다.

## yfinance 티커 접미사

| 지역 | 접미사 |
|---|---|
| 한국 | `.KS` (KOSPI), `.KQ` (KOSDAQ) |
| 미국 | 없음 |
| 일본 | `.T` |
| 중국 | `.SS` (상하이), `.SZ` (선전), `.HK` (홍콩) |
| 유럽 | `.PA .AS .BR .LS .DE .SW .L .MI .MC .ST .CO .HE .OL .VI .IR` |

지역 판정은 접미사로 자동 처리됩니다(`roic_screener/universe.py`).

## 금융주를 시드에서 빼지 마세요

시드에 금융주가 포함되어 있는 건 의도적입니다.
"시총 상위 100"의 의미를 지키려면 금융주도 랭킹에 넣고 나서 제외해야 합니다.
미리 빼면 "금융 제외 시총 상위 100"이 되어 사용자가 지정한 필터와 달라집니다.
제외된 종목은 `제외종목` 시트에 사유와 함께 남습니다.
