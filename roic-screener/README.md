# ROIC 상위기업 스크리너

무료 데이터 소스로 **한국·미국·일본·중국·유럽**의 시가총액 상위 100 기업 중
**ROIC 상위 30**을 뽑아 엑셀로 출력합니다.

```bash
cd roic-screener
pip install -r requirements.txt

python run.py --regions us                      # 먼저 한 지역으로 시험
python run.py --regions all --out roic.xlsx     # 5개 지역 전체
```

## 시작하기 전에 — 이 도구의 한계 3가지

정직하게 먼저 말해둘 것들입니다. 결과를 오해하면 잘못된 종목을 사게 됩니다.

**1. "시총 상위 100"은 시드 리스트 안에서의 상위 100입니다.**
무료로 전 종목 시총 순위를 주는 API 는 중국(akshare)뿐입니다. 나머지 4개 지역은
`seeds/*.txt` 에 넣은 후보군 안에서 정렬합니다. 시드에 없는 대형주는 후보에 못 들어옵니다.
→ `seeds/README.md`

**2. 지금 들어 있는 시드는 검증되지 않았습니다.**
모델 지식(2026-05 기준)으로 작성한 목록이라 오탈자·상장폐지 종목이 섞여 있을 수 있습니다.
실행 후 엑셀 **`조회실패` 시트**를 보고 시드 파일을 고쳐 쓰세요. 그게 정상 워크플로입니다.

**3. 이 저장소를 만든 환경은 네트워크가 막혀 있어 실제 수집을 검증하지 못했습니다.**
계산 로직·엑셀 출력은 오프라인 픽스처로 86개 테스트를 통과했지만, Yahoo 응답의 실제
계정 라벨과 맞물리는 부분은 사용자 로컬에서 첫 실행을 해봐야 확인됩니다.
깨지면 `조회실패`/`제외종목` 시트 내용을 알려주시면 고칠 수 있습니다.

## ROIC 정의 (이걸 먼저 고정해야 순위가 안정됩니다)

측정 기간은 **2024-01-01 ~ 2026-06-30** 을 하나의 창으로 봅니다.

```
실효세율 t = clamp( Σ법인세비용 / Σ세전이익 , 10%, 40% )
             계산 불가 시 지역 법정세율 (kr 24 / us 25 / jp 30 / cn 25 / eu 25 %)

NOPAT      = Σ EBIT(창 구간) × (1 − t)

투하자본 IC = 총차입금 + 자본총계(비지배지분 포함) − 초과현금
             초과현금 = max(0, 현금및단기금융상품 − 매출 × 2%)

ROIC       = ( NOPAT ÷ (커버일수/365.25) ) ÷ 평균 IC
```

설계상의 선택과 이유:

| 항목 | 선택 | 이유 |
|---|---|---|
| 자본 범위 | 비지배지분 **포함** | EBIT 이 비지배지분 차감 전이라 분자·분모를 맞춰야 한다 |
| 투하자본 시점 | 창 전후 **모든 재무상태표 평균** | 기말 한 시점만 쓰면 대형 인수·자사주매입 직후 ROIC 가 왜곡된다 |
| 영업권 | 기본 **포함** (`--exclude-goodwill` 로 제외) | 인수대가도 투입한 자본이라는 정통 관점 |
| 리스부채 | Yahoo `Total Debt` 에 포함되는 대로 | IFRS 는 필수 계상. 회사별 편차가 있어 원값을 `계산근거` 시트에 노출 |
| 세율 클램프 | 10~40% | 일회성 세무이슈로 실효세율이 −50%/+120% 로 튀는 사례가 흔하다 |
| 회계연도 정렬 | **보정하지 않고 실측 구간을 노출** | 일본 3월 결산은 창과 어긋난다. 억지로 맞추면 없는 데이터를 만들어내는 셈 |

일본(3월 결산)은 커버 구간이 `2024-04-01 ~ 2026-06-30`(약 90%)로,
미국(12월 결산)은 `2024-01-01 ~ 2026-06-30`(100%)로 나옵니다.
**서로 다른 기간의 ROIC를 비교하고 있다는 사실이 `기간커버` 컬럼에 그대로 표시됩니다.**
유럽 반기보고 기업은 '26 1H 미공시 시 커버율이 80%까지 떨어집니다.

### 스크리닝 순서

1. 지역별 시가총액(USD 환산) 상위 100
2. **금융·부동산(리츠)·유틸리티 제외** — 투하자본 개념이 성립하지 않아 ROIC 비교가 무의미
3. 평균 투하자본 $50M 미만 제외 (껍데기 법인의 ROIC 폭발 차단), 커버율 55% 미만 제외
4. ROIC 상위 30

금융주는 **시드에서 빼지 않고** 랭킹에 넣은 뒤 제외합니다. 미리 빼면
"금융 제외 시총 상위 100"이 되어 지정한 필터와 달라집니다.

## 출력 엑셀 구성

| 시트 | 내용 |
|---|---|
| `설명` | 산식 정의, 실행 파라미터, 적용 환율, 한계·면책 — **먼저 읽을 시트** |
| `TOP30_통합` | 5개 지역 통합 ROIC 순위 |
| `<지역>_TOP30` | 지역별 순위 |
| `계산근거` | NOPAT·투하자본·실효세율·사용 보고기간 — 엑셀만 보고 재검산 가능 |
| `시총상위100` | 유니버스 전체 + 선정/제외 상태 |
| `제외종목` | 제외 사유별 |
| `조회실패` | 티커 오류·상장폐지·수집 실패 → **시드 수정용** |

메인 시트 컬럼: ROIC · EV/EBITDA · 업종 · 현재가 · 52주 최고/최저 · 역대 최고/최저(+기준일) ·
현재가/역대최고 · 지역 시총순위 · 시가총액 · 거래소 · 매매단위 · 미래에셋 온라인 가능 여부 · 기간커버 · 주의

역대 최고/최저가는 **액면분할만 보정**한 종가입니다. 배당까지 보정한 수정주가를 쓰면
"실제로 거래된 적 없는 가격"이 역대 최고가로 나오기 때문입니다.
증자·감자 보정 누락과 Yahoo 히스토리 시작일 제약이 있어 기준일을 함께 출력합니다.

## 데이터 소스 현황

### 실제로 쓰는 것

| 지역 | 소스 | 상태 |
|---|---|---|
| 전 지역 | Yahoo Finance (yfinance) | 재무·주가·시총 백본. 비공식 래퍼 — 계정 라벨 변경·IP 차단 가능 |
| 중국 | akshare (`--akshare`) | A주 전종목 시총 스냅샷. **유일하게 진짜 시총 순위** |

yfinance 가 백본인 이유는 5개 지역을 한 인터페이스로 무료 커버하는 유일한 선택지이기
때문입니다. 대신 처음부터 깨질 것을 전제로 만들었습니다 — 디스크 캐시(같은 날 재실행은
네트워크 미사용), 호출 간 대기+지터, 지수 백오프 재시도, 계정 라벨 별칭 매핑,
실패는 예외 대신 `조회실패` 시트로 수집.

### 원본 공시 교차검증 (선택)

상위에 오른 종목만큼은 원본으로 확인하는 게 안전합니다.

| 지역 | 모듈 | 필요 조건 |
|---|---|---|
| 미국 | `roic_screener/sources/sec.py` | 없음. SEC XBRL companyfacts, API 키 불필요 (User-Agent 에 이메일 필수, 초당 10건) |
| 한국 | `roic_screener/sources/dart.py` | DART 무료 API 키 (`DART_API_KEY` 환경변수) |

### 넣지 않은 것과 그 이유

- **일본 EDINET API v2** — 무료·키 발급 가능하지만 회사별 확장 XBRL 태그 매핑 비용이 큽니다.
  계정명이 회사마다 달라 정규화 작업이 이 프로젝트 규모를 넘습니다.
- **유럽 ESEF (filings.xbrl.org)** — 연차보고서만 있어 '26 1H 반영이 원천적으로 불가합니다.
- **중국 cninfo(巨潮资讯)** — 법정 소스지만 PDF 위주라 자동 파싱이 비현실적입니다.
- **pykrx** — 2026년부터 KRX 로그인(`KRX_ID`/`KRW_PW`)을 요구해 무인증 수집이 막혔습니다.
  한국 시총·주가는 yfinance `.KS`/`.KQ` 로 받습니다.

5개 지역 파이프라인을 원본 공시로 직접 짜는 비용을 생각하면, 정규화된 유료 API
(FMP, EODHD 등 월 $30~100)로 백본을 바꾸고 XBRL 은 검증용으로만 쓰는 편이 효율적입니다.
`Provider` 프로토콜(`roic_screener/provider.py`)만 구현하면 갈아끼울 수 있게 만들어 뒀습니다.

## 매수 경로 (미래에셋증권 기준, 반드시 직접 확인)

기억하는 범위(2026-05)이며 취급 시장은 자주 바뀝니다. 고객센터나 앱 해외주식 메뉴에서 확인하세요.

| 지역 | 온라인(m.Stock) | 실무 제약 |
|---|---|---|
| 미국 | 가능 | OTC(비후원 ADR)는 미지원 가능성 높음 |
| 일본 | 가능 | **매매단위 100주** — 키엔스·패스트리테일링급은 1회 수천만원 |
| 중국 A주 | 가능 (후강퉁/선강퉁) | 편입종목만, 100주 단위, 외국인 보유한도 |
| 홍콩 | 가능 | 매매단위 종목별(100~2,000주), 인지세 0.1% |
| **유럽** | **미지원 (오프라인 전화주문)** | 영 인지세 0.5%, 프 FTT 0.3%, 아일랜드 1% |

**아직 정하지 않으신 것 — 유럽 처리 방법.** 선택지 셋입니다:
NYSE/NASDAQ 정식상장 ADR로 한정(ASML·SAP·NVO·AZN·SHEL 등 — 유럽 고ROIC 상위 30을 못 채움),
유럽만 IBKR 등 해외 브로커 병행(양도소득세 직접 신고, 잔액 5억 초과 시 해외금융계좌 신고),
또는 유럽 제외.

배당 원천징수(참고): 일본 15.315% / 중국 10% / 독일 26.375% / 스위스 35% /
프랑스 최대 28%(환급 번거로움) / 영국 0%. 양도차익은 어디서 사도 22%(연 250만원 공제).

## 주요 옵션

```bash
--regions kr,us,jp,cn,eu    # 또는 all
--top-mcap 100              # 유니버스 크기
--top-roic 30               # 최종 선정 수
--window-start 2024-01-01   # ROIC 측정 창
--window-end   2026-06-30
--exclude-goodwill          # 투하자본에서 영업권 차감
--min-ic-usd 50e6           # 투하자본 하한
--min-coverage 0.55         # 커버율 하한
--akshare                   # 중국 전종목 시총 순위 사용
--cache-dir .cache          # 캐시 위치
--cache-days 1              # 캐시 유효기간
--interval 1.2              # 호출 간 대기(초). 낮추면 IP 차단 위험 ↑
```

**첫 실행 권장 순서**

```bash
python run.py --regions us --top-mcap 20 --top-roic 10   # 작게 시험
python run.py --regions us                                # 지역 하나 완주
python run.py --regions all --out roic.xlsx               # 전체
```

5개 지역 전체는 캐시가 비어 있으면 종목당 1~6회 호출 × 약 800종목이라
`--interval 1.2` 기준 1시간 이상 걸립니다. 캐시가 있으면 재실행은 즉시 끝납니다.

## 개발

```bash
python -m pytest tests/ -q     # 86개 테스트, 네트워크 불필요
```

테스트는 `FakeProvider` 로 Yahoo 를 대체해 파이프라인 전체를 실제로 돌리고
xlsx 를 만들어 다시 읽어 검증합니다. ROIC 는 손으로 검산한 값과 대조합니다
(`tests/test_roic.py::test_roic_matches_hand_calculation`).

```
roic_screener/
  config.py       지역·산식 파라미터·제외업종  ← 정의를 바꿀 곳
  roic.py         ROIC 엔진 (순수 함수, 네트워크·pandas 없음)
  prices.py       분할 보정 주가 통계 (순수 함수)
  fields.py       재무제표 계정 별칭 매핑  ← Yahoo 라벨 변경 시 고칠 곳
  fx.py           USD 환산
  provider.py     수집 계층 + 캐시 + 재시도  ← 소스 교체 지점
  universe.py     시드 로딩, 지역 판정, akshare
  exclusions.py   업종 제외 규칙
  screener.py     오케스트레이션 (2패스)
  excel.py        엑셀 출력
  cli.py          CLI
  sources/        원본 공시 교차검증 (SEC, DART)
seeds/            지역별 후보 티커
scripts/          시드 갱신 스크립트
```
